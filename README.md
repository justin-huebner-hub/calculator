# The Calculterminator

A simple desktop calculator application built with JavaFX.

## Features

- Basic arithmetic: addition, subtraction, multiplication, division
- Decimal number support
- Clear (`C`) and Clear Entry (`CE`) functionality
- Basic error handling (e.g. division by zero)

## Requirements

- Java 17 or higher
- Maven

## How to Run

Run the app from the terminal using Maven:

```bash
mvn javafx:run
```

Or open the project in your IDE (IntelliJ IDEA, Eclipse, etc.) and run `StartUp.java`.

## Tests

Run the test suite:

```bash
mvn test
```
